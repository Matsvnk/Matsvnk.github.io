Privacy policy

Clipscraper · last updated 16 November 2026

What Clipscraper is

Clipscraper is a personal, self-hosted application that runs on its owner's own computer. It is used only by its developer and is not offered to the public.

Google user data it accesses

Clipscraper requests a single Google permission: youtube.upload. It uses this permission only to upload short videos to the YouTube channel of the account that signed in, and to set the title, description and tags of those videos. It does not read, modify or delete any other YouTube or Google data.

How data is stored

  • The OAuth access and refresh tokens are stored only on the owner's own computer.
  • No Google user data is sent to, stored on or shared with any server or third party other than Google's own APIs.
  • Google user data is not sold, used for advertising, or used to train AI models.

Compliance

Clipscraper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files from the computer running Clipscraper removes all stored credentials.
